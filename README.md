# Featured Projects

<details>
<summary><b>🚉 Tambaram Railway Station Junction — 3D Traffic Simulation</b></summary>

<br/>

An interactive **3D traffic simulation concept** focused on modelling the environment around **Tambaram Railway Station Junction, Chennai**.

The project combines web development, real-time 3D rendering and performance-oriented engineering to create a dynamic digital representation of a busy transportation environment.

### Engineering Highlights

| Category | Details |
|---|---|
| Stack | React • Three.js • React Three Fiber |
| Rendering | WebGL / Real-time 3D |
| Vehicle Simulation | 1000+ vehicles |
| Optimization | InstancedMesh |
| Environment | Roads • Buses • Auto-rickshaws • Traffic |
| Architecture | Component-based React architecture |
| Focus | Performance-conscious 3D rendering |

### Engineering Approach

The primary challenge is handling a large number of moving objects while maintaining an efficient rendering pipeline.

The project explores **InstancedMesh-based rendering**, reusable 3D components and React-driven scene architecture to reduce unnecessary rendering overhead.

This project represents my interest in combining:

**Software Engineering + 3D Graphics + Simulation + Performance Optimization**

</details>
